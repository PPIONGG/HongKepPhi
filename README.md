# ห้องเก็บผี

เว็บ Next.js สำหรับเก็บเรื่องผีที่เจ้าของห้องฟังมาจาก YouTube แล้วอยากชี้ทางให้คนอื่นกดไปฟังคลิปต้นฉบับได้

## รันโปรเจกต์

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000)

## หน้าในห้อง

- `/` วิทยุ เปิดมาจูนรอที่เรื่องล่าสุด หมุนหน้าปัดหาเรื่อง กด SCAN สุ่มเรื่องที่ยังไม่ฟัง หรือกดปุ่มจำคลื่นเพื่อไปที่ชุดเรื่อง
- `/stories/<slug>` แฟ้มคดีของแต่ละเรื่อง มีคลิปแนบ คำเตือน บันทึกของปอง ชุดเรื่อง และตราประทับฟังแล้ว
- `/shelf` ชั้นเทปในห้องมืด ส่องไฟฉายหาเทป หรือกดสวิตช์เปิดไฟให้อ่านง่าย

## เพิ่มเรื่องใหม่

แก้ไฟล์ `src/data/stories.ts` แล้วแปะก้อนข้อมูลเรื่องใหม่ไว้บนสุดของอาร์เรย์

- `channel` ใส่ชื่อช่องตาม YouTube ให้ตรงกันทุกเรื่องของช่องนั้น เช่น `THE GHOST RADIO` หรือ `Tang Makkaporn` วิทยุจะแยกเป็นย่านความถี่ตามช่อง และชั้นเทปจะแยกเป็นตู้ตามช่องเอง
- อยากเปิดตู้ไว้ก่อนทั้งที่ยังไม่มีเรื่อง ให้จดช่องใน `src/lib/channels.ts` วิทยุจะมีย่าน AM ที่ยังไม่มีสัญญาณ และชั้นเทปจะมีตู้เปล่ารอไว้
- `youtubeId` คือรหัสหลัง `v=` ในลิงก์ เช่น `https://www.youtube.com/watch?v=2-u9-RuHUjc` ใช้ `2-u9-RuHUjc`
- `note` คือบันทึกของเจ้าของห้อง ว่าทำไมถึงเก็บเรื่องนี้
- เรื่องบนสุดของอาร์เรย์คือเรื่องที่เพิ่งเก็บ วิทยุจะจูนรอไว้ที่เรื่องนี้ และเทปม้วนนี้จะติดสติกเกอร์ "ใหม่" เองโดยไม่ต้องตั้งค่าอะไร
- `tags` ใส่ได้ 5-8 อัน กดแท็กในหน้าแฟ้มแล้วจะไปที่ `/shelf?tag=` เทปที่มีแท็กเดียวกันจะเรืองแสง ส่วน `/?tag=` ทำให้คลื่นที่มีแท็กนั้นเรืองแสงบนหน้าปัดวิทยุ

## คำเตือนเนื้อหา

ใส่ `warnings: ["แท้งลูก", "อุบัติเหตุ"]` ในเรื่องที่มีเหตุการณ์หนัก จะขึ้นเป็นกรอบเตือนเหนือคลิปในหน้าแฟ้ม เหนือปุ่มฟังในการ์ดที่วิทยุจูนอยู่ ในปกเทปที่ชั้นเทป และในแถบปุ่มฟังด้านล่างจอบนมือถือ

หลักการคือ **ตรงไหนมีปุ่มกดออกไป YouTube ได้ทันที ตรงนั้นต้องเห็นคำเตือนก่อน**

คำเตือนกดไม่ได้ ต่างจากแท็ก — แท็กมีไว้ให้หาเจอ คำเตือนมีไว้ให้หลบทัน

เรื่องที่ไม่มีอะไรหนักเป็นพิเศษ ไม่ต้องใส่ฟิลด์นี้เลย

## เพิ่มชุดเรื่อง

แก้ `src/data/series.ts` สำหรับเรื่องที่เล่าต่อกันเป็นตอนๆ

ตอนที่ยังไม่ได้เก็บใส่แค่ `order` กับ `title` พอเก็บคลิปนั้นเข้าตู้แล้วค่อยเติม `slug` — หน้าเว็บอัปเดตสถานะเองทั้งชุด ไม่ต้องแก้ที่อื่น

แต่ละชุดจะกลายเป็นปุ่มจำคลื่นบนวิทยุ และเป็นแถบสีบนหัวเทปของทุกม้วนในชุด

`Story` ไม่มีฟิลด์ชี้กลับไปหาชุดโดยตั้งใจ ข้อมูลชุดอยู่ที่ `series.ts` ที่เดียว จะได้ไม่มีสองฝั่งที่ต้องคอยแก้ให้ตรงกัน

## เพิ่มหมวดใหม่

เรื่องที่ไม่เข้าหมวดไหนเลย ใส่ `category: "other"` ได้ ไม่ผิด ความเฉพาะเจาะจงไปอยู่ในแท็กแทน — ดีกว่ายัดลงหมวดที่ใกล้ที่สุดแบบฝืนๆ

เมื่อ `other` มีเรื่องแนวเดียวกันครบ **3 เรื่อง** ค่อยตั้งเป็นหมวดจริง:

1. เพิ่มบรรทัดใน `CATEGORIES` (`src/lib/types.ts`)
2. เลือกสีตลับเทปของหมวดนั้นใน `PALETTES` (`src/components/shelf/tapes.ts`) ถ้ายังไม่ใส่ บิลด์จะไม่ผ่าน
3. แก้ `category` ของสามเรื่องนั้น

**หมวดที่รอเลื่อนขั้นตอนนี้:** หมู่บ้าน / ชนบท (มี 1 เรื่อง)

## สคริปต์

- `npm run dev` — เปิดโหมดพัฒนา
- `npm run build` — สร้างไฟล์สำหรับขึ้นโฮสต์
- `npm run start` — รันบิลด์ที่เสร็จแล้ว
