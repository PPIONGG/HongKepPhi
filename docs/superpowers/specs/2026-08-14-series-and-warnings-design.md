# ชุดเรื่องที่เชื่อมกัน และคำเตือนเนื้อหา

วันที่: 2026-08-14

## ปัญหา

คลิป "ที่เก่า" ของคุณเคเล่าค้างไว้ แล้วมีอีกสองคลิป ("บังเอิญ", "ขอให้จบ")
ที่เล่าต่อเป็นเรื่องเดียวกัน ฟังเรียงลำดับแล้วประติดประต่อได้ — ตอนนี้เว็บ
ไม่มีที่เก็บความสัมพันธ์แบบนี้เลย มีแค่ `tags: string[]` แบนๆ

พร้อมกันนั้นเรื่องหนึ่งมักมีแท็กเกินสามอัน และบางอันไม่ใช่แท็กชนิดเดียวกัน
"เชียงใหม่" บอกว่าเรื่องอยู่ที่ไหน (ไว้ให้คนหา) ส่วน "แท้งลูก" บอกว่าเรื่องมี
อะไรหนัก (ไว้เตือนคนก่อนกด) สองอย่างนี้ปนกันในลิสต์เดียวไม่ได้

## สิ่งที่ตัดสินใจแล้ว

1. ชุดเรื่อง **มีลำดับ** — ตอน 1, 2, 3 ไม่ใช่กลุ่มเรื่องลอยๆ
2. ตอนที่ยังไม่ได้เก็บ **ยังต้องโชว์** เป็นช่องว่างในโครงชุด
3. คำเตือนเนื้อหา **แยกจากแท็กปกติ** คนละที่ คนละหน้าตา
4. ชุดเรื่อง **ไม่มีหน้าของตัวเอง** เป็นแค่กล่องในหน้ารายเรื่อง
5. หมวดสถานที่ **มีที่พักสำหรับของที่ไม่เข้าพวก** แทนที่จะพยายามเดาให้ครบ

## สถาปัตยกรรม

### ชุดเรื่องเป็นข้อมูลของตัวเอง ไม่ห้อยกับเรื่องใดเรื่องหนึ่ง

ไฟล์ใหม่ `src/data/series.ts` เป็นแหล่งข้อมูลชุดเรื่อง **แหล่งเดียว**

```ts
{
  slug: "khun-k",
  title: "เรื่องเล่าของคุณเค",
  blurb: "สามคลิปที่คุณเคเล่าต่อกัน ฟังเรียงแล้วประติดประต่อได้",
  episodes: [
    { order: 1, title: "ที่เก่า", slug: "thi-kao" },
    { order: 2, title: "บังเอิญ" },
    { order: 3, title: "ขอให้จบ" },
  ],
}
```

`slug` ในตอนหนึ่งๆ มีความหมายเดียว: **เก็บเข้าตู้แล้ว** ถ้าไม่มี `slug`
แปลว่ายังไม่เก็บ ไม่ต้องมีฟิลด์ `collected` แยก — สถานะอ่านจากข้อมูลได้เอง

ตอนที่ยังไม่เก็บ**ไม่ต้องมี `youtubeId`** เพราะเว็บไม่ได้พาไป YouTube
ถ้าวันหนึ่งอยากให้กดออกไปฟังได้ ค่อยเติมฟิลด์ตอนนั้น

### `Story` ไม่มีฟิลด์ชี้กลับไปหาชุด

ตั้งใจไม่ใส่ `seriesSlug` ใน `Story` เพราะจะกลายเป็นข้อมูลสองฝั่งที่ต้อง
ตรงกันตลอด แล้ววันหนึ่งจะลืมแก้ฝั่งใดฝั่งหนึ่ง เว็บหาย้อนกลับเอาจาก
`episodes[].slug` แทน

```ts
getSeriesForStory(storySlug) → { series, episode } | undefined
```

`series.ts` ไม่ import `stories.ts` และ `stories.ts` ไม่ import `series.ts`
หน้ารายเรื่องเป็นคนเรียกทั้งสองฝั่ง — ไม่มี circular import

### คำเตือนเนื้อหาเป็นฟิลด์ธรรมดาใน `Story`

```ts
warnings?: string[]   // ["แท้งลูก", "อุบัติเหตุ"]
```

ไม่มีชนิดตายตัว เขียนอะไรก็ได้ตามที่ฟังเจอ — แท็กปกติก็ไม่ตายตัวอยู่แล้ว

**คำเตือนกดไม่ได้** ต่างจากแท็ก แท็กมีไว้ให้หาเจอ คำเตือนมีไว้ให้หลบทัน
ไม่มีใครอยากกดดูรวมเรื่องแท้งลูกทั้งหมด

## Type ที่เพิ่ม (`src/lib/types.ts`)

```ts
export type SeriesEpisode = {
  order: number;
  title: string;
  slug?: string;
};

export type Series = {
  slug: string;
  title: string;
  blurb: string;
  episodes: SeriesEpisode[];
};

export type Story = {
  // ...ของเดิมทั้งหมด
  warnings?: string[];
};
```

## คอมโพเนนต์ที่เพิ่ม

### `SeriesBox` — กล่องชุดเรื่อง

รับ `series` กับ `currentSlug` แสดงตอนทั้งหมดเรียงตาม `order` สามสถานะ:

| สถานะ | หน้าตา | กดได้ |
|---|---|---|
| ตอนที่กำลังอ่าน | เน้นสีถ่าน (ember) | ไม่ |
| เก็บแล้ว | ปกติ | ใช่ → `/stories/[slug]` |
| ยังไม่เก็บ | จาง + ป้าย "ยังไม่ได้เก็บ" | ไม่ |

### `ContentWarnings` — แถบคำเตือน

แถบเส้นขอบซ้ายสีถ่าน ข้อความ "เรื่องนี้มี: ..." คั่นด้วยจุลภาค

## ตำแหน่งที่แสดง

**หลักการ: ตรงไหนมีปุ่มกดออกไป YouTube ได้ทันที ตรงนั้นต้องเห็นคำเตือนก่อน**

| ที่ | คำเตือน | กล่องชุดเรื่อง |
|---|---|---|
| หน้ารายเรื่อง | เต็ม ก่อนถึงคลิป | ใต้ใบจด |
| การ์ดในชั้นวาง | ย่อ (`⚠ แท้งลูก +2`) | ไม่มี |
| เรื่องเด่นหน้าแรก | ย่อ | ไม่มี |

`RelatedStories` ("ชั้นเดียวกัน") ยังอยู่เหมือนเดิม แต่กล่องชุดเรื่องมาก่อน
เพราะความสัมพันธ์แบบชุดแน่นกว่าแบบหมวดเดียวกัน

## แท็กปกติ

ขยับจาก 3 เป็น **5-8 อัน** โครงเดิม กดได้เหมือนเดิม ไม่ต้องแก้โค้ด
เป็นการเปลี่ยนที่ prompt อย่างเดียว

## หมวดสถานที่

### ปัญหาที่แท้จริงไม่ใช่ลิสต์สั้นไป

7 หมวดเดิมมาจากตอนสร้างเว็บ ซึ่งบังเอิญพอดีกับ 11 เรื่องที่มีอยู่ตอนนั้น
ไม่ได้แปลว่าพอสำหรับเรื่องผีไทยทั่วไป — โรงพยาบาล ค่ายทหาร เรื่องในน้ำ
ตึกร้าง ไม่มีที่ลงเลยสักอัน

แต่ต่อให้เติมอีกสิบหมวดก็ยังไม่พออยู่ดี พรุ่งนี้เจอเรื่องผีบนเครื่องบิน
เรื่องผีในเหมือง ก็ตันอีก **ปัญหาคือระบบไม่มีที่ให้ของที่ไม่รู้จะลงตรงไหน
ไปอยู่** พอไม่มีที่ลง agent ก็ยัดมั่ว — เหมือนที่มันยัด "รวมเรื่อง" ให้ "ที่เก่า"

### ลิสต์ใหม่: 12 หมวด

| id | label | hint |
|---|---|---|
| `home` | บ้าน | บ้าน ห้องเช่า คอนโด |
| `hotel` | โรงแรม | โรงแรม ที่พัก |
| `school` | โรงเรียน | โรงเรียน มหาลัย |
| `forest` | ป่าเขา | ป่า เขา ทางเปลี่ยว |
| `temple` | วัด | วัด สถานที่ศักดิ์สิทธิ์ |
| `road` | ถนน | รถ ทาง เดินทาง |
| `hospital` | โรงพยาบาล | โรงพยาบาล คลินิก ห้องดับจิต |
| `military` | ทหาร | ค่ายทหาร เกณฑ์ทหาร |
| `water` | ทะเล/แม่น้ำ | ทะเล เรือ แม่น้ำ คนจมน้ำ |
| `ruins` | ตึกร้าง | ตึกร้าง คอนโดร้าง โรงงานร้าง |
| `mix` | รวมเรื่อง | คลิปรวมหลายตอน |
| `other` | อื่นๆ | ที่ที่ยังไม่มีชั้นของตัวเอง |

### `other` คือที่พักถาวร ไม่ใช่ที่ทิ้งขยะ

เรื่องที่ไม่เข้าพวกลง `other` ได้เลย ไม่ผิด ไม่ต้องฝืน ความเฉพาะเจาะจง
ไปอยู่ในแท็กแทน — เรื่องผีเครื่องบินยังมีแท็ก `เครื่องบิน` ให้คนกดหาเจอ

**กฎเลื่อนขั้น:** เมื่อ `other` มีเรื่องซ้ำแนวกันครบ **3 เรื่อง** ให้ตั้งเป็น
หมวดจริง — เพิ่ม 1 บรรทัดใน `CATEGORIES` แล้วแก้ `category` ของ 3 เรื่องนั้น

แปลว่าลิสต์หมวดโตตามของจริงที่เก็บ ไม่ใช่ตามที่เดาไว้ล่วงหน้า

### ปุ่มกรองต้องซ่อนหมวดที่ยังไม่มีเรื่อง

12 หมวด = ปุ่มกรอง 13 ปุ่ม แต่ตู้มีเรื่องเดียว กด 12 ปุ่มเจอ "ชั้นนี้ยังว่าง" หมด

`StoryShelf` ต้องสร้างปุ่มจากหมวดที่**มีเรื่องอยู่จริง**เท่านั้น (`ทั้งหมด`
อยู่เสมอ) ตอนนี้จะเห็นแค่ `ทั้งหมด` กับ `บ้าน` ปุ่มอื่นโผล่เองเมื่อเก็บเรื่อง
แนวนั้นเข้ามา — ทำให้เพิ่มหมวดล่วงหน้าได้แบบไม่มีต้นทุนหน้าจอ

### หนี้ที่รู้ตัวแต่ยังไม่จ่าย

`mix` ไม่ใช่หมวดสถานที่ อีก 11 อันตอบว่า "เกิดที่ไหน" แต่ `mix` ตอบว่า
"คลิปหน้าตาแบบไหน" — คนละแกน คลิปรวมเรื่องป่าเป็นทั้งสองอย่างแต่เลือกได้อันเดียว

ยังไม่แก้ตอนนี้เพราะรื้อโครงเพื่อเรื่องเดียวในตู้ไม่คุ้ม ถ้าวันไหนคลิปรวมเยอะขึ้น
ค่อยแยกเป็นฟิลด์ `format` ต่างหาก

## จะรู้ได้ยังไงว่าถูก

1. `/stories/thi-kao` เห็นกล่องชุด 3 ตอน — ตอน 1 เน้น ตอน 2-3 จาง
2. ตอน 2-3 ไม่มีลิงก์ กดไม่ได้
3. หน้าแรกการ์ด/เรื่องเด่นเห็นคำเตือนย่อ
4. เรื่องที่ไม่มี `warnings` ไม่ขึ้นแถบว่าง
5. เรื่องที่ไม่อยู่ในชุดไหน ไม่ขึ้นกล่องชุด
6. ปุ่มกรองในชั้นวางเห็นแค่ `ทั้งหมด` กับ `บ้าน` — ไม่ใช่ 13 ปุ่ม
7. `tsc --noEmit`, `eslint`, `npm run build` ผ่าน

## ที่ตั้งใจไม่ทำ

- **หน้า `/series/[slug]`** — มีชุดเดียว ยังไม่คุ้ม
- **ลิงก์ YouTube ในตอนที่ยังไม่เก็บ** — ขัดกับที่ห้องนี้ตั้งใจ (เก็บเฉพาะที่ฟังแล้ว)
- **คำเตือนกดได้** — ไม่มีใครอยากไล่ดูเรื่องหนักๆ ทั้งหมด
- **ชนิดคำเตือนตายตัว** — ไม่รู้ล่วงหน้าว่าจะเจออะไรบ้าง

## Prompt สำหรับ agent ที่ฟังคลิปได้ (v2)

````markdown
ช่วยฟังคลิปนี้แล้วสรุปข้อมูลให้หน่อยครับ
<วางลิงก์ที่นี่>

ผมจะเอาไปลงในเว็บสะสมเรื่องผีส่วนตัว ขอผลลัพธ์เป็น 8 อย่างนี้:

1. summary — เนื้อเรื่องย่อ 3-5 บรรทัด ว่าใครเจออะไร ที่ไหน เกิดอะไรขึ้น
2. category — เลือก 1 อย่างจากลิสต์นี้ ห้ามแต่งหมวดใหม่เอง:
   บ้าน / โรงแรม / โรงเรียน / ป่าเขา / วัด / ถนน /
   โรงพยาบาล / ทหาร / ทะเล-แม่น้ำ / ตึกร้าง / รวมเรื่อง / อื่นๆ

   - "รวมเรื่อง" ใช้เฉพาะคลิปที่เอาหลายเรื่องมาต่อกันเท่านั้น
     เรื่องเดี่ยวไม่ว่าจะยาวแค่ไหนก็ไม่ใช่รวมเรื่อง
   - ถ้าไม่มีอันไหนตรงจริงๆ ให้ตอบ "อื่นๆ" แล้วบอกต่อว่า
     ถ้าให้ตั้งชื่อหมวดเองจะตั้งว่าอะไร
   - ห้ามเลือกอันที่ใกล้ที่สุดแบบฝืนๆ ตอบ "อื่นๆ" ดีกว่าเดาผิด
3. guest — ชื่อคนเล่า (ถ้าพิธีกรเรียกชื่อในคลิป)
4. excerpt — คำโปรย 1 ประโยค ไม่เกิน 25 คำ
5. note — บันทึก 2-4 ประโยค ว่าเรื่องนี้เด่นตรงไหน น่าเก็บเพราะอะไร
6. tags — 5-8 แท็กภาษาไทยสั้นๆ ครอบคลุม
   สถานที่ (จังหวัด/ภาค) · ประเภทสถานที่ · คนในเรื่อง · สิ่งของสำคัญ · ยุคสมัย
7. warnings — เหตุการณ์หนักในเรื่อง สำหรับเตือนคนก่อนกดฟัง
   เช่น แท้งลูก / ฆ่าตัวตาย / อุบัติเหตุ / ความรุนแรงในครอบครัว / ทารุณสัตว์
   ถ้าไม่มีอะไรหนักเกินเรื่องผีทั่วไป ตอบว่า "ไม่มี"

8. series — คลิปนี้เกี่ยวโยงกับคลิปอื่นของคนเล่าคนเดียวกันไหม
   - คนเล่าหรือพิธีกรพูดถึงคลิปก่อนหน้า/ตอนต่อไปไหม
   - มีบอกไหมว่าเรื่องยังไม่จบ หรือจะกลับมาเล่าต่อ
   - ถ้ามี บอกชื่อคลิปที่เกี่ยวข้องและลำดับที่ควรฟัง
   - ถ้าไม่มี ตอบว่า "ไม่มี"

กติกาของ excerpt กับ note:
- ห้ามสปอยล์ตอนจบ บอกได้แค่ว่าหลอนแนวไหน
- เขียนแบบคนฟังจดไว้เอง ไม่ใช่รีวิวหรือโฆษณา
- ห้ามใช้คำพวก "สุดหลอน" "ห้ามพลาด" "ขนลุกทั้งคลิป"
- ชี้ให้เห็นว่าเรื่องนี้ต่างจากเรื่องผีทั่วไปยังไง
- ห้ามแต่งเรื่องส่วนตัวของผมเอง (เช่น "ฟังตอนตีสอง") เพราะคุณไม่รู้

ข้อ 7 กับ 8 ต่างจาก excerpt/note ตรงที่ **สปอยล์ได้**
warnings มีไว้เตือน ถ้าอ้อมค้อมจนไม่รู้ว่าเตือนอะไรก็ไร้ประโยชน์
````
